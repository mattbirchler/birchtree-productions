See the changes as Claude makes them.

Every file Claude touches shows up live, with its additions and deletions. Click one for the full diff, and leave comments on lines to send back to Claude.

Terminal or chat, same session.

Claude Code runs in a real terminal built on Ghostty, so it uses your font, theme and keybindings. Press ⌥⌘T and the same session turns into a chat: edits show as diffs, commands fold their output away, and questions become cards with real buttons. It's still Claude Code underneath, so you can flip back any time.

Agents

Hand off the work. Keep your branch.

Every agent gets its own git worktree and branch, so a few of them can work at once without stepping on you or each other.

Brain Dump: say it all at once.

Press ⌥⌘N and talk through everything you want done, across all your projects. Claude splits it into one task per project, each with a branch and a prompt you can edit or move to another project. Nothing starts until you click Start, and then they all run side by side.

Every session at a glance.

Sessions that need you sit at the top, then the ones Claude is working on, then the ones that are done. Get notified for the projects you choose, or put every session on your Lock Screen at once.

Your code goes from your Mac to your phone.

The iPhone app talks to your Mac over your own Tailscale network, so your code never passes through our servers. Notifications are encrypted on your Mac so only your phone can read them.

And the rest

And a lot of small things.

Overview.

Every Claude session across every project in one grid, with the ones that need you first. ⌘J jumps to the next one.

Go anywhere.

⌘K opens a command bar for any project or action: switch projects, start an agent, or begin a Brain Dump.

Usage and costs.

See what your sessions would cost at API prices, by day, model and project.

One-click shortcuts.

Add tab shortcuts for commands you run all the time. JavaScript projects get a dev server button and a preview tab.

Pick up where you left off.

Resume past conversations in one click, and your tabs come back when Workbench relaunches.

Your draft stays put.

Text in the message box is still there when you switch projects and come back.

Menu bar status.

See what's working and what needs you without switching apps.

A welcome that sets you up.

It checks for the tools it needs, signs you in to Claude Code, suggests projects, and pairs your iPhone.

Updates itself.

New versions download in the background and install when you quit.
