Every project gets its own workspace.

See the changes as Claude makes them.

Every file Claude touches shows up live, with its additions and deletions. Click one for the full diff, stage what you like, and see which commits your branch has that the base doesn't.

Hand work to agents on their own branches.

Start an agent with a prompt and Bench gives it a fresh git worktree, so it can't step on what you're doing. Each one shows its own status, its pull request, and whether checks passed. When the PR merges, Bench can clean up the worktree for you.
